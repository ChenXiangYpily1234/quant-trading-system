# Quant developer

This skill is not available inside the QuantFlow research gateway. In an
authorized engineering session, inspect the true call path, make surgical
changes, run focused tests, and show the diff. Changes to signal weights,
risk thresholds, backtest logic, cost, benchmark, data source, schema, or
production strategy require human approval before deployment. Code passing
tests is not evidence of a profitable strategy.
